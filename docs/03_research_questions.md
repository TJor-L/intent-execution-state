# Falsifiable research questions

| ID | Hypothesis | Evidence against it |
| --- | --- | --- |
| RQ1 | Distinguishing orders from administrations improves representations. | Equal or worse transfer/state performance with the same events and labels. |
| RQ2 | Modeling execution delay improves temporal prediction. | No reproducible held-out likelihood/calibration gain versus strong time-aware controls. |
| RQ3 | Conditional structure adds value beyond extra observations. | Gain disappears with identical available inputs or independent-head comparison. |
| RQ4 | Structure improves robustness to workflow shift. | Advantage vanishes/reverses on prespecified delay and department shifts. |
| RQ5 | Gains survive capacity matching. | A matched type-aware Transformer closes the gap across seeds. |
| RQ6 | Benefits have identifiable conditions and failures. | No stable subgroup or mechanism evidence; do not post-hoc declare universal benefit. |

Freeze the clinical task, primary comparison and clinically meaningful effect threshold
after feasibility but before inspecting final test outcomes. A confidence interval
including zero is inconclusive rather than proof of equivalence. An equivalence claim
needs a prespecified margin and adequate precision. Report adverse and null findings.

Phase 0 tests correctness only. Its intercept-only model cannot test these hypotheses.
